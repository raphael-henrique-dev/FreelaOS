# FreelaOS

## Visão Geral

FreelaOS é o Cursor para freelancers: em vez de aumentar a produtividade durante a execução do trabalho, aumenta drasticamente a produtividade na aquisição de clientes.

FreelaOS é um Sistema Operacional para Freelancers baseado em Inteligência Artificial.

O objetivo do produto não é apenas organizar projetos ou funcionar como um CRM tradicional. Seu propósito é atuar como uma equipe comercial completa, composta por agentes de IA especializados que trabalham continuamente para encontrar oportunidades, avaliar projetos, preparar propostas, acompanhar clientes e administrar o negócio do freelancer.

O usuário deve sentir que possui uma empresa trabalhando para ele 24 horas por dia.

A Inteligência Artificial é o produto principal. Todas as demais funcionalidades existem para apoiar o trabalho desses agentes.

---

# Filosofia

FreelaOS não é um ERP.

FreelaOS não é um CRM.

FreelaOS não é apenas um painel.

FreelaOS é um "AI Business Operating System", onde agentes inteligentes executam tarefas normalmente realizadas por uma equipe comercial.

Sempre que possível, a interface deve transmitir a sensação de que existe uma equipe trabalhando em segundo plano.

O usuário não executa tarefas repetitivas.

O usuário apenas supervisiona, aprova decisões importantes e acompanha resultados.

---

# Problema que resolve

Hoje um freelancer precisa:

- acessar diversas plataformas;
- procurar oportunidades manualmente;
- comparar projetos;
- calcular se vale a pena;
- escrever propostas repetitivas;
- acompanhar respostas;
- organizar clientes;
- controlar pagamentos;
- gerenciar projetos.

Tudo isso consome horas diariamente.

FreelaOS automatiza esse processo.

---

# Objetivo Principal

Reduzir drasticamente o tempo gasto para conseguir novos clientes.

O sistema deve:

• encontrar oportunidades

• analisar automaticamente

• priorizar as melhores

• preparar propostas personalizadas

• acompanhar clientes

• organizar projetos

• controlar faturamento

Tudo centralizado em um único lugar.

---

# Conceito de Agentes

O sistema é composto por agentes especializados.

Cada agente possui uma única responsabilidade.

Exemplos:

## Scout IA

Responsável por localizar oportunidades.

Busca vagas em plataformas como:

- Workana
- 99Freelas
- Upwork
- Freelancer
- LinkedIn
- outras integrações futuras

Suas responsabilidades:

- encontrar projetos
- remover duplicados
- extrair requisitos
- monitorar novas oportunidades

---

## Analista IA

Responsável por avaliar cada oportunidade.

Ele calcula um Score de Compatibilidade utilizando critérios como:

- stack tecnológica
- remuneração
- prazo
- retorno financeiro por hora
- dificuldade técnica
- experiência anterior
- interesse do usuário
- chance estimada de aprovação

Sempre deve explicar por que atribuiu determinado score.

O sistema nunca deve ser uma caixa-preta.

---

## Redator IA

Responsável por elaborar propostas.

A proposta deve considerar:

- histórico do cliente
- experiências do freelancer
- projetos semelhantes
- linguagem profissional
- diferenciais técnicos

O envio sempre depende de aprovação humana.

---

## Assistente IA

Responsável pelo relacionamento.

Monitora:

- respostas
- mensagens
- follow-ups
- lembretes

Resume conversas longas.

Sugere respostas.

Nunca responde automaticamente sem autorização do usuário.

---

## Financeiro IA

Gerencia:

- pagamentos
- contratos
- notas fiscais
- fluxo de caixa
- faturamento
- indicadores financeiros

# Interface

A interface deve transmitir a sensação de um software premium.

Referências:

- Linear
- Vercel
- Stripe Dashboard
- Raycast
- Notion
- Arc Browser

Características:

- minimalista
- moderna
- elegante
- poucas cores
- muito espaço em branco
- animações suaves
- tipografia forte
- design focado em produtividade

Tema escuro como padrão.

---

# Dashboard

O Dashboard não deve apenas mostrar números.

Ele deve mostrar trabalho sendo realizado.

Ao abrir o sistema, o usuário deve entender imediatamente:

"O que minha equipe de IA fez enquanto eu estava fora?"

Exemplos:

• oportunidades encontradas

• propostas preparadas

• clientes responderam

• projetos fechados

• tarefas pendentes

O Dashboard deve sempre responder:

"O que exige minha atenção agora?"

---

# Comunicação

Os agentes possuem personalidade profissional.

Eles comunicam suas atividades de maneira objetiva.

Exemplos:

"Encontrei 12 novas oportunidades."

"Esta vaga recebeu score 91."

"Preparei uma proposta personalizada."

"O cliente respondeu há 15 minutos."

Nunca utilizar linguagem exageradamente robótica.

- Design
- Marketing
- Copywriting
- Arquitetura
- Tradução
- Engenharia

---

# Regra mais importante

Sempre que uma nova funcionalidade for criada, pergunte implicitamente:

"Essa funcionalidade ajuda os agentes de IA a trabalharem melhor ou ajuda o usuário a gerenciar sua equipe de IA?"

Se a resposta for não, ela provavelmente não pertence ao FreelaOS.
